# Walden

Walden 在 macOS 上从本机微信读取经过授权的消息，并增量同步到本地副本。查询读取这个副本，可以按联系人、群聊或日期查阅消息。结果会提供覆盖状态、副本的观测时间，以及仍有缺口的范围。最新查询以副本当前可见的消息为准。

后台同步监听 macOS 文件事件。数据库及其 WAL、SHM 文件的变化是检查提示，后台也会定期检查。Walden 通过 SQLite 确认变化并复制数据，无需解析 WAL 文件。同步进度取决于本机微信的数据、后台状态和副本覆盖。

- 已明确授权同步时，指定会话范围的配置可以显式刷新。账号范围配置通过单独授权的后台服务同步，查询仍然读取副本。
- 已保存的图片和音频可按配置处理。附件不可用时仍保留消息正文，并标明相关缺口。
- 回复兼容功能依赖既存事件证据，发送前仍需确认。新副本的消息引用不能直接用于发送。
- 今后可探索使用这个副本建立关系记忆。当前版本提供消息同步和查询。
